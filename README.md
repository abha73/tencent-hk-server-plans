## 常见问题

**腾讯云香港服务器需要备案吗？**
不需要 ICP 备案。香港地域不在备案范围内，域名解析到服务器 IP 就能访问。

**20Mbps 和 200Mbps 实际差多少？**
峰值差 10 倍。20Mbps 大约每秒 2.5MB 的下载速度，够跑文字站和小图；200Mbps 理论每秒 25MB，配合不限流量才撑得住文件分发和视频场景。

**香港轻量能装 Windows 吗？**
能，但同配置价格更高，而且购买后不能与 Linux 互换。远程桌面用途选 Windows，建站优先 Linux。

**99元/年和 288元/年到底哪个能买？**
99元/年是当前活动位上的境外地域年付价（2核2G / 30M / 1T）。288元/年是更早一轮香港活动的报价，仍被很多旧文引用，不必拿它当现价去比对。

**续费会涨价吗？**
除标注“续费同价（限1次）”的套餐外，其余按续费时的官网价执行。活动折扣只作用于首个计费周期。

**国际站的 $4.2/月 是不是更便宜？**
国际站以美元计价，套餐配置和国内站不完全对应（比如通用型给的是 2核4G / 90G 盘 / 2.5T 流量），结算方式也不一样，别直接按汇率换算来对比两边价格。
